## 发现与优先级

### P1：后台日志筛选在桌面宽度发生覆盖

**浏览器实证。** 1280×720，`/admin/log-center` 的 AI 日志选择“自定义”后，结束时间按钮的矩形右边缘约 1082px，而状态选项区域从约 1025px 开始，垂直方向也重叠，结束时间被状态区域遮住；状态选项换行。`apps/web/features/admin/invocation-logs-filters.tsx:185` 在 xl 起将预设、时间范围和状态筛选放入横行，但子项有最小宽度。AI 与语音日志共用此组件；内置浏览器在语音日志的同一视口选择自定义时间后也观察到结束时间被状态区域遮挡。建议按内容可用宽度换行或分行，保证各控制可见可点，不改日期范围的排序与筛选语义。

### P1：登录/注册选项卡不支持方向键

**浏览器实证 + 源码。** 重置链接无效页打开认证弹窗，登录选项卡聚焦后按右方向键，焦点和选中状态未切到注册；鼠标点击可以切换。`apps/web/features/auth/auth-dialog.tsx:88` 手工给按钮标注 `tablist`/`tab`，仅实现点击，没有选项卡键盘管理。项目已有 `components/ui/tabs.tsx`。建议用现有 Tabs 的 line 变体组合，并核对登录、注册、找回密码切换、焦点与表单草稿；也可保留按钮语义，但不应保留不完整的 tab 语义。

### P1/P2：服务商配置的输入缺少稳定名称

**浏览器辅助树 + 源码。** 编辑后台服务商时，代理输入和余额配置输入在辅助树中没有对应字段名称；`apps/web/features/admin/ai/ai-provider-form.tsx:265` 至 303 使用 Input 和 placeholder，但未关联 FieldLabel 或 aria-label，折叠区标题不能为各个输入提供名称。建议使用已有 Field、FieldLabel、FieldDescription，让名称在输入后仍可见或被辅助技术识别，保持保存和密钥语义。

### P2：模型和声音选择器跨个人端与后台分叉

**源码 + 浏览器实证。** 个人设置 `settings-page.tsx:166,670,1262`、`settings/tts/settings-tts-section.tsx:136` 使用原生 select（其中声音控件由循环生成三个），后台用途绑定使用已有 Combobox，后台语音使用已有 Select。个人与后台相同的选择任务会经历不同的展开与搜索方式，原生弹出列表还受系统外观控制。优先根据选项规模采用已有 Select/Combobox；确有移动系统原生选择优点时考虑官方 Native Select，统一触发器样式但明确系统弹层无法完全主题化。保留空值、分组、禁用项、provider-qualified 模型、草稿与保存行为。

### P2：遗漏的选择控件和状态语义

- `library/library-page.tsx:316` 排序为原生 select；`admin/public-categories/source-category-mappings.tsx:164,190` 为自定义样式原生 select。评估对应 Select、可搜索 Combobox 或 Native Select；分类量大时优先研究搜索，但不要改变分析、确认和提交时机。
- `settings/settings-page.tsx:1174` 自动整理为原生 checkbox，视觉上与后台的 Switch 不同；`library/library-tag-assignment-dialog.tsx:161` 为原生复选框，浏览器已观察。前者是持久开关，后者是多选集合，应分别采用现有 Switch / 官方 Checkbox 候选，而不是将二者做成同一种语义。保留各自保存与即时行为。
- `settings/tts/settings-tts-section.tsx:63` 和 `settings/settings-page.tsx:1130` 的默认/自有服务为普通按钮，通过填色表达选择，辅助树仅报告按钮，未报告选中状态。建议比较 ToggleGroup 或 RadioGroup，保留当前显式保存与取消方式。

### P2：普通弹窗和菜单缺少共同表层

**源码，浏览器核对上传、标签管理和确认弹窗。** 登录、上传、标签管理各自直接组合 Base Dialog 原语，位于 `auth/auth-dialog.tsx:50`、`library/library-upload-dialog.tsx:78`、`library/library-tag-assignment-dialog.tsx:39`，项目没有共享普通 Dialog。三者不是缺少底层无障碍原语，但遮罩、圆角、头尾、间距、关闭位置分别定义。已有 AlertDialog 是确认模式，Sheet 是侧向面板，不应代替普通 Dialog。建议引入 shadcn Dialog 并建立符合产品主题的共享头部/内容/操作区及尺寸变体；统一角色、关闭、焦点和小屏滚动，允许认证版式和确认版式适度不同。

顶部 `components/navigation/account-menu.tsx:3` 和 `theme-mode-control.tsx:3` 直接使用 Base Menu 并重复样式，而 `components/ui/dropdown-menu.tsx` 已提供分组、单选项、分隔线。可基于已有封装合并外壳，保留语言/主题单选、焦点和头像内容；与书籍操作菜单对照，建立一致的菜单状态和层级。

### P2：移动端“更多”实现与设计规范冲突

**浏览器实证 + 规范冲突。** 在 390×844 点击底部“更多”，实际导航至 `/more` 全页；`components/navigation/mobile-bottom-nav.tsx` 使用 Link。`DESIGN.md:548`–550 则锁定底部 Sheet、无 `/more` 路由。两者不能同时作为当前权威，应确认该规范是否过期或实现偏离；在没有产品决策前不建议直接删路由或强行切换。

### P2/P3：认证、发现、阅读器和加载状态存在可复用机会

- 认证表单 `auth/auth-field.tsx` 及登录、注册、重置表单另建 Field、Input 和社交按钮样式；账户表单已使用共享 Field/Input。可新增受控变体、组合社交按钮，保留认证密度、隐藏标签和校验行为。
- 发现页分类 chip、书库状态过滤、阅读音色等手工按钮组，可评估现有 ToggleGroup/按钮变体；要先区分单选、可取消筛选与操作按钮，保留 aria 状态及具体交互。`discover/discover-pagination.tsx` 自行绘制页码；已有 Pagination 的链接组件固定为 `<a>`，应组合容器和 Button 或扩展按钮支持，保留有界页码、禁用状态及移动端加载更多。
- 搜索输入含内部清除动作（`discover/discover-search.tsx`），可评估已有 InputGroup；保留输入与提交分离以及清除语义。
- 多处使用手写 `animate-pulse` 骨架，如 account、history、discover、book-detail、library、reader 和 settings；已有 Skeleton，可集中颜色/运动行为，仍保留每页真实的骨架形状及加载无障碍状态。自定义空态/错误提示也可对照 Empty/Alert，但有插画、重试或阅读上下文的场景应保留业务差异。
- 阅读器的三个锚定浮层直接用 Base Popover，而现有 `PopoverContent` 已支持 anchor 和碰撞参数；可评估组合共享外壳，必须保留虚拟选区锚点、滚动定位、角色、焦点及手机 Sheet。阅读音频旋转封面等特殊交互不应机械替换。Reader AI 两个输入只提供 placeholder（`reader-ai-drawer.tsx:261`、`reader-ai-inline.tsx:130`），建议补稳定可访问名称；现已在桌面侧栏、桌面选区提问和手机 Sheet 的辅助树中确认。

## 原因与建议顺序

项目并非完全没有组件库：共享控件和主题 token 已存在；缺口主要是普通 Dialog/Checkbox 等未建立、同一需求在业务层并存多种实现、以及组件封装无法自动保证正确语义和响应式。具体历史原因未知。建议先修复键盘、命名和遮挡，再确定组件选型规则和弹层模式，随后分业务域迁移与浏览器回归。每批保留持久化、确认、网络触发与现有产品语义；优先修改共享变体前评估全部使用者。

## P1：手机发现页无法进入后续结果

**内置浏览器实证 + 源码。** 390×844 的 `/discover` 底部显示 15 张来源记录卡片，没有“加载更多”；DOM 中桌面分页显示总计 4219 页但在手机隐藏。`apps/web/features/discover/discover-page.tsx` 每次请求 `DISCOVER_PAGE_SIZE=15` 条，`mobileVisible` 初始也是 15，`hasMoreMobile` 仅比较当前页数组长度是否大于该值，因此正常分页响应中不会出现加载更多。`discover-pagination.tsx` 在手机只渲染 `hasMoreMobile` 为真时的按钮，而页码导航只在 `md` 及以上显示，手机无法到下一页。旧目录列表使用同一模式，当前公开作品样本为零，故旧目录部分是源码推断。建议实现真实跨页追加加载或提供手机分页，保留筛选、搜索、加载错误、重复数据和返回位置；不能仅把按钮显示出来而仍停留在同一页。未保存、导入任何作品。
