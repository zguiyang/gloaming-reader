## 用户最终目标与明确约束

- 保持项目现有主题、配色、整体布局和业务行为，消除局部弹窗、选择器、按钮等与页面风格脱节、粗糙或原生外观不一致的问题。
- 范围不限于弹窗、按钮、下拉框、日期、复选框或选项卡：先了解已有 shadcn/ui 能力，再逐页面检查；优先复用已有组件、变体或组合，确实不适合时保留有理由的专用实现。不要为了消除原生标签而破坏必要的浏览器接口或特殊交互。
- 除组件实现，还需核对交互模式、可访问性、键盘焦点、错误与加载、响应式和视觉一致性。不得将静态扫描或少量样本误报为全页面、全状态通过。
- **所有页面操作、视觉验收和截图只用 Codex 内置浏览器（IAB）；不要使用用户本机 Chrome、其他浏览器或外部浏览器自动化替代。**
- 用户已明确决定：**移动端“更多”暂时保持现有 `/more` 页面行为**。即使 `DESIGN.md` 曾要求底部 Sheet，也不要在此任务中擅自改导航或删除路由。
- 后续验证不要调用真实 AI、发送真实问题、触发真实语音生成；用隔离的本地假数据/回调或纯单元测试模拟状态。不要提交真实配置、密码、文件或执行清理。临时验证页面必须无外部副作用，结束后移除。
- 遵循仓库根 `AGENTS.md`、相关 `rules/frontend.md`、`DESIGN.md` 和适用 Skills；用户明确指令优先。不要使用未授权的 worktree、迁移、清库、生产操作、推送或合并。需要持久数据写入的自动化测试必须使用经确认的隔离测试环境。

- 已依据原始报告修复手机发现页不能翻到后续结果、后台日志日期和状态控件重叠、日历方向键不移动焦点、短横屏编辑抽屉不可滚动等问题。

- 补足模型字段错误反馈与关联、服务商及阅读器输入名称、后台和认证选项卡面板关联、章节展开状态、链接语义、历史/日志入口上下文；加载遮罩活动时下层内容 `inert`，禁用分页退出键盘顺序。
- 阅读器桌面关闭侧栏不可进入 Tab 顺序；隐藏顶部工具栏在键盘聚焦时显示。正文现有可命名的键盘焦点入口；已有正文选区在释放 Shift 后可打开操作组，Escape 清除并把焦点返回正文。鼠标选区仍可打开提问框。

- 模型字段、音频控件和长回复使用**本地隔离模拟**做过浏览器检查，临时页面已删除；没有把模拟结果描述成真实服务集成通过。相关实现详情、页面观察和例外见[修复与验证报告](修复与验证报告.md)。

## 仍需处理与明确未验证

1. **纯键盘从零选词仍未验证成功，是最重要的开放项。** 内置浏览器中正文聚焦后，Home / Shift+方向键未产生文字选区，F7 也未建立可验证的光标浏览。已经有选区后的 Shift/工具栏/Escape 交接在浏览器及模拟单测中通过，但不等于纯键盘可以独立建立选区。后续应先研究并验证浏览器/系统可用的键盘文本选择机制，再决定是否需要产品内明确的键盘选词入口；不要将正文做成可编辑内容或破坏阅读、双语选句、鼠标选区、焦点和滚动。任何新交互要保持主题并满足项目规则。
2. **阅读器音频未做真实集成验收。** 已用模拟播放器验证状态展示、口音、速度、进度和焦点；控制器的模拟测试覆盖缓冲、暂停、错误、切换及进度。真实音频请求、播放、切段与真实服务不可据此宣称通过。用户当前禁止真实 AI 和语音生成，后续不得自行突破该限制。
3. **部分数据/错误/流式及跨设备状态缺受控样本。** 包括后台来源分类待审核分支、个人模型多服务商与已保存模型不可用、语音长错误、封面真实加载失败、真实流式回复、所有页面的双语言/明暗色/窄屏/短屏/长文案和真实读屏软件。优先使用不写共享环境、不触发真实服务的本地隔离模拟；明确区分代码推断、单元模拟与内置浏览器实测。
4. **原报告其余候选仍要有依据地复核。** 原始 151 文件静态清点不能证明无遗漏。审查共享组件边界和仍保留的自定义 UI：已有业务特殊性或浏览器必要接口的组件可保留，并说明原因；确实可复用的遗漏应补齐。不要把 `variant="plain"` 当成已经完成视觉设计，应检查焦点、禁用、响应式、文字截断、加载遮罩及交互语义。
5. 继续对已提交改动进行针对性 review，尤其是共享 `Button` 的 `plain` 变体、`Dialog`/`Checkbox`/`Progress`/`Collapsible` 的项目主题适配、`LoadingOverlay` 的 inert、分页链接、`settings-page.tsx` 的模型空值/禁用/服务商分组/草稿与保存，以及阅读器选区 Popover 的关闭和焦点。审查是否有视觉或业务回归。

## 建议接手流程

1. 只读检查当前分支、HEAD、提交历史、所有未提交和未跟踪文件；读本目录两份报告，区分原始发现与后续已修复状态。

3. 在不调用真实 AI 或生成语音的前提下，优先处理纯键盘选词及受控错误/长内容样本；需要可视化时只用内置浏览器，临时模拟文件在验收后清理，明确记录其模拟性质。

5. 如有后续修复，检查并独立复核后按依赖关系提交；向用户汇报已完成、真实浏览器实测、模拟验证、无法验证和 Git 状态。涉及推送、合并、生产或真实 AI/语音须另有明确授权。
