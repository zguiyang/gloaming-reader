# Gloaming UI 修复与验证报告

基于《Gloaming UI 与组件复用审查》及其补充清单，修复保持现有主题和既有业务流程。报告编写时工作区为 `dev-02` 且修改尚未提交；此后代码已分批本地提交，当前 Git 状态与提交记录以《交接说明》和实时 Git 为准。以下区分实现、浏览器观察与未验证项；不将代表样本检查称为所有状态通过。

## 已实现

- 手机发现页新增可进入其他结果页的分页；后台 AI 和语音日志筛选可以按可用空间换行。
- 认证选项卡、输入和社交按钮复用现有组件，选项卡关联内容面板；书库排序、个人服务及语音选择、个人 AI 模型用途和后台来源分类选择复用 Select。原生多选改为基于 shadcn Base UI 的 Checkbox，自动整理开关复用 Switch；服务模式补充选中状态。
- 新增与现有主题一致的共享 Dialog 外壳，认证、上传和标签管理复用；顶部账户和外观菜单复用 DropdownMenu；阅读器选区工具、词典、AI 提问浮层复用 Popover。
- 修复日历日期方向键；阅读器关闭侧栏不再进入键盘顺序，隐藏的顶部工具栏在聚焦时显示；阅读器输入有可访问名称，选区工具改用普通分组语义。内联 AI 浮层增加高度限制与滚动。
- 后台模型参数校验显示并关联错误，服务商输入和公共分类名称输入补充名称；AI 日志详情加入时间和来源上下文，语音日志长错误允许换行。后台 AI 页选项卡关联面板。
- 短横屏个人作品编辑抽屉可滚动；书库、作品详情、历史主要阅读入口及后台主导航恢复链接语义；章节按钮报告展开状态；紧凑封面加载失败时回退；手机首页标题平衡换行。

## 尚未完成或需要产品决策

- 手机“更多”：现有 `/more` 页面与 DESIGN.md 要求的底部 Sheet 冲突。直接改为 Sheet 会改变现有导航行为；在没有明确产品决策的情况下保留现状，既没有删除路由，也没有擅自改写设计规范。
- 审查中作为复用候选的所有手写骨架、进度条、搜索组合、特殊阅读器按钮和所有 Button + Link 入口尚未逐一迁移。文件上传的原生 file input 等浏览器接口和特殊阅读行为不应机械替换。需要逐处核对行为和收益，不能声称项目已经没有自定义组件或不存在遗漏。
- 后台来源分类选择的特定待审核数据状态、个人模型多服务商/失效模型在真实数据中的全部路径、两种语言和所有暗色/窄屏/短屏组合仍未全面验收。

## 无法或尚未实测

- 模型 Temperature 和 Max tokens 均在不接后端的单元测试中验证了错误关联和阻止提交；此前自动审批拒绝了在真实后台提交无效草稿的操作，因为可能产生持久写入，故不将其标为浏览器实测通过。
- 开发环境语音日志无失败样本，长错误换行缺少真实长错误浏览器样本；图片失败回退、长 AI 流式回复和全部加载/错误状态也缺少受控浏览器样本。
- 没有进行真实 AI 提问或真实 TTS 生成，没有上传文件、提交配置或更改密码。查词调用了现有词典功能；打开阅读器产生正常开发环境阅读状态和心跳写入。没有迁移或清理数据库。
- 官方 shadcn CLI 的 registry 查询在当前网络下未返回，已查阅官方 Base UI 组件文档及上游源码；新增 Checkbox 和 Dialog 按该组合及本项目语义样式适配，未声称是 CLI 自动安装的原样文件。

## 共享原子件规则纠正与指示条规范化（2026-11-01 深夜）

**规则纠正。** 复核 [rules/frontend.md](../../rules/frontend.md) 后确认：共享原子件（`apps/web/components/ui/*`）源码的修改需要任务授权。上一轮提交 `3acd940d` 直接改了 `components/ui/dialog.tsx`，属于越界；已用 `git revert` 回滚（`96bc83fd`），`components/ui` 恢复原样，`auth-dialog.tsx` 的动画覆盖随之恢复。

**改为两层合规做法：**

- 主题层覆盖（`apps/web/app/globals.css` 末尾新增「Theme-layer control overrides」）：
  - `[data-slot='dialog-overlay']` 统一为黑色 10% 遮罩，修复暗色下 `foreground` 是浅色导致的“白蒙层”；
  - `[data-appearance='filled']:focus-visible` 强制 `border-color: transparent`，让 filled Input / Textarea / SelectTrigger 聚焦时只保留 2px offset ring，不再出现两条高亮线。已核对编译产物：规则位于 utilities 之后，能压过 `focus-visible:border-ring`。
- 使用点 className 覆盖：
  - 登录/注册 tab：只在 `auth-dialog.tsx` 上覆盖 `group-data-horizontal/tabs:h-auto`、`h-auto`、`after:bottom-[-2px]!`，不改 `tabs.tsx`；编译产物确认 `!important` 生效，且 `h-auto` 规则排在共享 `h-8` 之后。
  - 选中态统一为 2px 方角条：书库状态筛选与发现分页用底部条；后台服务商列表、阅读器目录用左侧竖条；阅读器引用卡、内联引用、Markdown 引用、后台词典示例用常显左侧条。全部通过 `before:` / `after:` + 条件 `opacity` 实现，未改 `Button` / `Tabs` / `control-appearance`。

**防回归。** 新增 `apps/web/test/design-guards.spec.ts`：扫描 feature 层，禁止单边 2px+ 边框指示条、禁止 focus 边框与 offset ring 叠加、禁止消费者自行覆盖 tab 指示条偏移，并断言主题层两条覆盖仍然存在。`DESIGN.md` 增加「Selection & focus indicators (locked)」小节，写明首选使用点 className、其次属性选择器主题覆盖、共享原子件需授权。

**本轮验证。** `pnpm --filter @gloaming/web test` 为 **70 个测试文件、549 项通过**（新增 guard 5 项）；`tsc --noEmit`、`eslint apps/web`、Prettier 通过；检查了 dev 编译产物中的关键规则顺序。**未做浏览器实测**：形状、对齐与暗色观感仍需在 IAB 或真实浏览器中逐项确认。
